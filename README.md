# RabbitQ Skills

兔子 Q 的 AI Skill 索引。独立可复用的 Skill 放在 `skills/各自的英文名/` 下，每个目录包含自己的 `SKILL.md` 和运行所需的资源。

## Skills

| Skill | 用途 |
| --- | --- |
| [gzh-image-hotspots](skills/gzh-image-hotspots/SKILL.md) | 给微信公众号图片局部加跳转链接，也能把多张图拼成长图，生成一个可一键复制到草稿的 HTML。 |
| [rabbitQ-lark2xhs](https://github.com/rabbit-Qbin/rabbitQ-lark2xhs) | 把飞书文档或 Markdown 转为可编辑的小红书图文，源码在独立仓库。 |

## 使用 Skill

打开需要的 `SKILL.md`，按文档提供输入。复制或安装 Skill 时带上整个目录。有运行依赖的 Skill 会在自己的目录内提供说明。
