# 公众号 SVG 排版

## 首次使用

先告诉用户可以给图片加局部链接，或按其要求把图片、GIF 和固定栏目排成一篇可复制的公众号图文。用户只问怎么开始时，用下面的格式一次收齐必要资料。

- 素材可以是原图、GIF 附件或本地文件路径。请提供素材顺序或文章分段。
- 要植入链接就同时给出「点击区域 → 链接」。可以用文字描述，也可以发标注截图。商品分享链、平台短链、普通网页链接和微信跳转包装链接均可提交。
- 要互动就描述效果，例如「点击罐身后淡出切到第二张」「三张图手动左右滑」「点局部放大，再点同处缩回」。
- 固定开头、社媒条或结尾按用户指定位置插入。没有给出位置且上下文无法判断时才问。素材齐全直接处理，只问影响交付的缺项。

## 排版约定

- 只把已提供的原图、正文和交互带进文章。点击或滑动提示由用户在制图时决定，只有用户明确要求才加入正文。
- 标注截图用于定位。先按共同视觉特征把框映射到干净的原图；坐标以 EXIF 显示方向为准。矩形格式为 `[左, 上, 右, 下]`，右下边界排他。文字已明确时直接定位，遇到歧义再问用户。
- 图片局部植入链接使用普通图片切片和原生链接。保留分享链定位参数，微信包装地址用其 `url` 参数解出目标；对图片区域做多个链接时检查对应关系和框外空白。
- 固定模块保存在账号工作区作为可编辑的模块 JSON。重复使用时引用同一份，按本篇顺序放在开头、中间或结尾。改内容先读现有模块和相关用户要求。通用 Skill 和可分发源码包里只放通用样例，账号原图和真实业务链接留在对应工作区。
- 若账号工作区有“公众号排版默认配置.json”，先读取其社媒入口和产品链接。账号的文末社媒模块默认放在正文末尾，用户指定位置或明确不要时以本篇要求为准；匹配产品名称时使用对应默认链接，本篇明确提供的链接优先。默认商品链接可能过期或指向不同 SKU，交付前核对产品名称与目标页。不要把账号配置、真实链接或图片提交到公开技能仓库。
- 新 HTML 有指定路径就用指定路径。同一任务有原测试入口就原地更新。新交付未指定时放到源图文件夹；长图素材同目录就放该目录。只拿到临时附件或涉及多个目录且位置不明时再询问。最终交付一个 HTML。

## 生成与验收

1. 按 [运行与配置](references/input.md) 生成单图或混合排版清单。图像处理使用 Pillow，用户无需写配置或量坐标。
2. **点击换图**用同尺寸的 A/B 两图和 A 图热区。使用 0.42 秒 SVG 淡出，点击后停在 B。内部坐标等比缩放以避免正文宽度缩小时被误判为高度溢出。公众号编辑器可能删除 SVG 自定义 `id`，不要依赖跨元素 ID 事件。若 B 图含链接，单独验证“热区切图、切换前不跳商品、切换后商品可跳”：后层祖先的 `pointer-events="none"` 可能在切图后仍锁住链接；前层热区若显式设置 `pointer-events="visible"`，即使前层组设为 `none`，热区仍可能覆盖 B 图。使用普通 HTML 图片链接时，还要检查保存后的正文是否保留链接，以及手机预览能否打开；本地静态检查与单次点击均不能代替此验收。热区按用户标注确定，不能为遮住后层链接擅自扩为整图。
3. **左滑、轮播、局部缩放、GIF**用独立版式。左滑跟随手势，轮播自动移动。局部放大以热区中心为锚点，再点同一位置缩回。GIF 以独立真动图段嵌入长图，用户已有 GIF 时直接保留帧，或用两张同尺寸图生成循环淡变 GIF。排版可以混合这些动效、带链接静态图和账号固定模块。
4. 验证图片顺序、触发位置、框外行为和链接。用 Chrome/Edge 实际复制粘贴到本地富文本区。可用时用微信结构检测工具检查正文片段，它不能代替手机草稿预览。公众号内确认图片处理结束、保存重开和手机触发，记录报错原文。检测失败时检查实际裁切和容器尺寸，只对有意横向滚动的容器使用规范允许的宽度标记。
5. 已有公众号实测的能力包括图片局部跳转及一次点击淡出换图。手动左滑、自动轮播、局部放大缩回、GIF 长图的样例经过本地验证后，交付时标明还需手机公众号草稿复测。保留一键复制工作流，正文不依赖执行 JavaScript。
